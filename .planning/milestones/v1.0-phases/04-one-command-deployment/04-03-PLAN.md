## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → `test/node_modules` | A new third-party package enters the developer's machine and the CI path |
| test app container `/app/db` → host filesystem | Must be a one-way dead end; any host mount here exposes real user data to test mutation |
| host environment → compose app service env | Host-set `MASSIVE_API_KEY` / `OPENROUTER_API_KEY` must not leak into the test container and make the suite non-deterministic or network-dependent |
