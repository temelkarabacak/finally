<objective>
Close UAT gap G-02-4: the P&L chart is stuck on its "Building portfolio history" empty state forever on a cold start unless the user makes a trade.

The phase's vertical slice already exists end to end — this restores one broken link in it. `usePortfolio`'s mount effect (frontend/hooks/usePortfolio.ts:154-156) calls `refresh()` exactly once, so the first `GET /api/portfolio/history` races the backend's first 30s snapshot tick, comes back `[]`, and nothing ever re-fetches until `TradeBar`'s `onTraded={refresh}` fires (frontend/app/page.tsx:68). `PnlChart`'s `showEmptyState = !ready || points.length < 2` (frontend/components/PnlChart.tsx:90) therefore never resolves on its own, contradicting D-04's promise that the chart fills in within ~60s of app start with no trade.

Diagnosis is authoritative and complete (02-UAT.md, gap G-02-4): the backend recorder and `GET /api/portfolio/history` were verified live and are correct. The fix is frontend-only and is a single effect in a single hook.

Purpose: make the P&L panel resolve itself on a cold start, as UI-05 and D-04 require.
Output: `frontend/hooks/usePortfolio.ts` polls on a repeating interval with unmount cleanup, plus an end-to-end confirmation that two history points exist inside the ~70s UAT window.
</objective>
